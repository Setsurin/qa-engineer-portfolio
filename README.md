# QA Engineer Portfolio

> 状态：搭建中（第 1 周）。本仓库是**基于公开练习系统的软件测试学习作品集**，不是商业项目经历。

## 这是什么

按「手工测试 → 测试设计 → API 测试 → SQL → Python 自动化」的顺序，逐步记录一次完整的软件测试练习过程。所有执行记录都标注日期、环境与预期结果依据；不编造用例、缺陷或执行结果。

## 测试对象

| 对象 | 用途 | 地址 |
| --- | --- | --- |
| SauceDemo | Web 手工测试 / UI 自动化 | https://www.saucedemo.com/ |
| Restful Booker | API 测试 | https://restful-booker.herokuapp.com/apidoc/index.html |
| 本地 SQLite | SQL 与数据校验 | 见 `05-sql-testing/database-setup.md` |

> SQLite 是独立的本地练习库，与上面两个网站的后台数据库无关。
